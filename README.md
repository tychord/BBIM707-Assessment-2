# BBIM707 – Advanced Data Engineering Assessment 2

## Project Overview
This project demonstrates ETL, data analysis, big data storage, real-time clustering and streaming pipelines using the Brazilian E-Commerce Public Dataset by Olist.

## Tools and Implementation

- **Python & Pandas:** Data extraction, cleaning, transformation, integration and visualisation.
- **Hadoop HDFS:** Data ingestion, integrity verification, backup and recovery.
- **MongoDB:** Data storage, aggregation, indexing and querying.
- **Apache Spark & Databricks:** K-Means clustering and simulated streaming using Spark Structured Streaming.
- **Apache Kafka:** Message production, consumption, consistency verification and recovery testing.

## Dataset
**Brazilian E-Commerce Public Dataset by Olist**

https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce
